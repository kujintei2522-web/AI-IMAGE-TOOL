# AI Background Studio

เว็บแอปลบพื้นหลังรูปภาพด้วย AI สำหรับใช้งานใน Google Chrome สร้างด้วย React + Vite และ `@imgly/background-removal`

## วิธีติดตั้งและเปิดใช้งาน

1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP นี้
3. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์
4. รันคำสั่ง:

```bash
npm install
npm run dev
```

5. เปิด URL ที่ Vite แสดง (โดยทั่วไปคือ http://localhost:5173)

## วิธีใช้งาน

1. เลือกรูป JPG, PNG หรือ WebP
2. กด “ลบพื้นหลังด้วย AI”
3. รอให้โมเดล AI ดาวน์โหลดและประมวลผล
4. เลือกสีพื้นหลัง หรือเลือกโปร่งใส
5. เลือกขนาด 1×, 2×, 4× หรือกรอกความกว้าง/สูงเอง แล้วกดดาวน์โหลด PNG

## หมายเหตุ

- การประมวลผลเกิดขึ้นในเบราว์เซอร์ รูปต้นฉบับไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของแอปนี้
- การดาวน์โหลดโมเดล AI ครั้งแรกต้องใช้อินเทอร์เน็ต และอาจใช้เวลาหรือหน่วยความจำมากตามขนาดรูปและอุปกรณ์
- หากต้องการเผยแพร่เชิงพาณิชย์ ให้ตรวจสอบเงื่อนไขสัญญาอนุญาตของ `@imgly/background-removal` และโมเดลที่ใช้งานก่อน
- โครงการนี้เป็นต้นแบบเริ่มต้น ยังไม่ได้ผ่านการทดสอบบนอุปกรณ์และเบราว์เซอร์ทุกแบบ


## การปรับขนาดภาพ

เวอร์ชันนี้รองรับการขยายภาพ 2×/4× และกำหนดขนาดพิกเซลเอง พร้อมล็อกอัตราส่วนภาพ ใช้การ resampling คุณภาพสูงของ Canvas ในเบราว์เซอร์ ไม่ใช่ AI super-resolution ที่สร้างรายละเอียดใหม่ หากต้องการเพิ่มรายละเอียดจริงควรเพิ่มโมเดล AI upscaler แยกต่างหาก


## ฟีเจอร์ปรับแสงและเงา (V3)
- ปรับความสว่าง คอนทราสต์ และความสดของสีของวัตถุที่แยกพื้นหลังแล้ว
- เพิ่ม/ปิดเงาตกกระทบ พร้อมปรับความฟุ้ง ความเข้ม และตำแหน่งเงาแนวนอน/แนวตั้ง
- ภาพตัวอย่างและไฟล์ PNG ที่ดาวน์โหลดจะใช้ค่าปรับชุดเดียวกัน
- คืนค่าการปรับแสงและเงาเริ่มต้นได้


## ฟีเจอร์เพิ่มความคมชัดและความละเอียด (V4)
- ปรับความคมชัดด้วย Sharpen filter ได้ตั้งแต่ 0–150%
- มีค่าลัด ปิด / ปกติ / คมชัด / คมมาก
- ใช้ร่วมกับการขยายภาพ 1×, 2×, 4× และกำหนดขนาดเองได้
- การขยายใช้ browser high-quality resampling ไม่ใช่ AI Super Resolution ที่สร้างรายละเอียดใหม่
- การ sharpen ทำในขั้นตอนส่งออก PNG จึงอาจใช้เวลาเพิ่มขึ้นกับภาพขนาดใหญ่มาก
